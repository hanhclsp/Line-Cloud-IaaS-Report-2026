# Hướng dẫn đưa báo cáo lên GitHub Pages

## Cách dùng

1. Tạo một repository trên GitHub, ví dụ `vnpt-report-hub`.
2. Upload 3 file:
   - `_config.yml`
   - `index.md`
   - `cloud-line-iaas-2026.md`
3. Vào **Settings → Pages**.
4. Chọn **Deploy from a branch**.
5. Chọn branch `main` và thư mục `/ (root)`.
6. Save.
7. GitHub sẽ tạo website dạng:
   `https://TEN-TAI-KHOAN.github.io/vnpt-report-hub/`

## Khi có báo cáo mới

Tạo thêm một file Markdown:

`cloud-line-iaas-2027.md`

Sau đó thêm liên kết vào `index.md`.

## Khuyến nghị

- Không đưa báo cáo nội bộ/mật lên repository public.
- Với tài liệu nội bộ, nên dùng GitHub Pages cho phần mục lục/tra cứu và lưu file gốc tại SharePoint/OneDrive/kho tài liệu nội bộ có phân quyền.
- Giữ mỗi báo cáo thành một trang Markdown để người đọc có thể mở trực tiếp trên trình duyệt.
